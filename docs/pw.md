# 비밀번호 관리 (페이지 접근 비밀번호)

맑은 비용절감 페이지는 **회원가입 없이** 단일 비밀번호로만 입장합니다.
비밀번호를 알고 있는 사람만 대시보드와 비용 상세 페이지를 볼 수 있습니다.

---

## 비밀번호 값은 어디서 확인하나요?

**이 문서에는 비밀번호 값을 적지 않습니다.** 코드 저장소(Git)에 남으면
히스토리에서 영구히 노출되기 때문입니다.

실제 비밀번호 값은 아래 외부 채널 중 한 곳에서 확인하세요.

- 1Password 공유 볼트의 `맑은 비용절감 페이지 접근 비밀번호` 항목
- (또는 팀 노션/슬랙 DM 등 사전에 합의된 비공개 채널)

> 비밀번호를 아는 사람에게만 공유하세요. 외부에 노출되면 즉시 변경해야 합니다.

---

## 비밀번호가 저장된 위치

비밀번호 값은 프로젝트 루트의 **`index.html`** 파일에 정의되어 있습니다.

```html
<script>
    // ============================================================
    // 페이지 진입 비밀번호 (회원가입 없음)
    // 변경 방법은 docs/pw.md 문서를 참고하세요.
    // ============================================================
    window.APP_PASSWORD = '<실제 값은 1Password 참고>';
    ...
</script>
```

---

## 비밀번호 변경 방법

1. 프로젝트 루트의 **`index.html`** 파일을 텍스트 에디터로 엽니다.
2. `window.APP_PASSWORD = '...';` 줄을 찾습니다.
3. 작은따옴표 안의 값을 새 비밀번호로 바꾸고 저장합니다.
   ```html
   window.APP_PASSWORD = '새로운비밀번호';
   ```
4. 브라우저에서 페이지를 **새로고침(F5)** 하면 즉시 적용됩니다.
5. 이미 입장해 있던 사용자도 브라우저 탭을 닫으면 다음 접속 시 새 비밀번호가 필요합니다.
6. **변경한 새 비밀번호 값은 이 문서에 적지 말고** 1Password 등 외부 채널에 갱신해 공유하세요.

## 동작 방식

| 항목 | 설명 |
|------|------|
| 로그인 화면 | `src/views/login.html` · `src/logic/login.js` |
| 인증 처리 | 입력값이 `window.APP_PASSWORD`와 일치하면 입장 허용 |
| 입장 상태 저장 | 브라우저 `sessionStorage` (키: `authToken`) |
| 유지 기간 | 브라우저 탭/창을 닫으면 해제 → 재입장 시 비밀번호 재입력 |
| 보호 범위 | `login` 페이지를 제외한 모든 페이지 (대시보드, 비용 상세) |
| 로그아웃 | GNB 우측 상단 "로그아웃" 버튼 → 입장 상태 즉시 해제 |

라우터 보호 설정은 `index.html`의 `ViewLogicRouter` 옵션에 있습니다.

```js
auth: true,
loginRoute: 'login',
publicRoutes: ['login'],   // 비밀번호 없이 접근 가능한 페이지
protectedRoutes: [],       // 비어 있음 = login 외 전부 보호
authStorage: 'sessionStorage',
```

---

## 보안 안내 (중요)

- 이 비밀번호 방식은 **간편한 접근 차단용**입니다. 정적 파일로 동작하므로,
  비밀번호 값이 `index.html` 소스에 평문으로 포함됩니다.
- 브라우저 개발자 도구로 소스를 열면 비밀번호를 확인할 수 있습니다.
  따라서 **민감한 기밀 데이터의 강력한 보호 수단으로는 사용하지 마세요.**
- 더 강한 보호가 필요하면 서버 측 인증(로그인 API) 도입을 검토해야 합니다.
